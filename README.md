# Practical-Assignment-4-Classification-Models

- This project implements four classification algorithms: SVM, Decision Tree, KNN, and Gaussian Naïve Bayes.
- The Iris Flower dataset is used for classification.
- Python and scikit-learn are used for implementation.
- The dataset is divided into training and testing sets.

## How to Run
1. Install dependencies: `pip install scikit-learn pandas numpy`
2. Run: `python classification_models.py`
